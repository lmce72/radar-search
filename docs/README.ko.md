# Radar Search

**Obsidian의 노트, 본문, 태그, 명령어와 웹을 한곳에서 검색하세요.**

[简体中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md)

빠른 조회에는 떠 있는 검색창을, 오래 살펴볼 때는 검색 페이지를 사용하세요. 대시보드 노트에 검색창을 넣을 수도 있습니다. Dataview나 아이콘 플러그인이 필요하지 않습니다. 현재 플러그인의 화면 문구는 중국어로 표시됩니다.

## 주요 기능

- 파일명, 본문, 태그, 속성, 북마크, 내부 링크와 외부 링크 검색. 중국어 검색도 지원하며, 본문 요약을 누르면 일치 위치로 이동합니다.
- 상단 범주 전환과 결과 정렬. 노트 또는 원하는 단계의 상위 폴더를 제외할 수 있습니다.
- 필터를 프리셋으로 저장. 폴더 자동 완성과 자주 쓰는 규칙 예제를 제공합니다.
- 검색어, 범주, 필터, 정렬을 유지하면서 검색창을 검색 페이지로 옮길 수 있습니다.
- 명령어 및 웹 검색, 밝은/어두운 테마 지원. 페이지 결과는 내부에서 스크롤되며 모바일 하단 컨트롤 공간을 확보합니다.

## 설치

**Obsidian 1.7.2 이상**이 필요합니다.

1. [최신 릴리스](https://github.com/lmce72/obsidian-radar-search/releases/latest)에서 `main.js`, `manifest.json`, `styles.css`를 받습니다.
2. 보관함 설정 폴더의 `plugins/primecore-search/`에 넣습니다. 기본 경로는 `.obsidian/plugins/primecore-search/`입니다.
3. 설정 → 커뮤니티 플러그인에서 **Radar Search**를 켭니다.

업데이트할 때는 이 세 파일을 교체하고 플러그인을 껐다 켜세요. 설정과 기록을 보존하려면 `data.json`과 `history/`를 유지하세요.

## 검색 시작

명령어 팔레트에서 **打开浮动搜索框**(떠 있는 검색창 열기) 또는 **打开搜索页**(검색 페이지 열기)를 선택합니다. 각각 단축키를 지정할 수 있습니다. 리본 아이콘은 검색창을 열며, Esc 또는 바깥 영역 클릭으로 닫습니다. 휴대폰이나 긴 검색 작업에는 검색 페이지가 편리합니다.

왼쪽에서 Vault, 전체, 인터넷 모드를 선택하세요. Vault와 전체 검색은 입력에 따라 갱신되며 Enter로 즉시 검색할 수 있습니다. 인터넷 검색은 Enter나 검색 버튼으로 검색 주소를 엽니다. **搜索选项**은 검색 옵션이며, 패널 오른쪽 위의 톱니바퀴로 플러그인 설정을 엽니다.

범주 이름은 마우스를 올리거나 키보드로 포커스할 때 표시됩니다. 터치 화면에서는 아이콘을 눌러 전환합니다. 결과가 없는 범주는 비활성화되고, 모든 결과가 비어 있으면 “什么都木有”가 표시됩니다. 필터는 계속 사용할 수 있어 제한을 해제할 수 있습니다.

### 노트에 검색창 넣기

다음 블록을 붙여 넣고 읽기 보기 또는 실시간 미리보기에서 사용하세요.

````markdown
```primecore-search
```
````

한 노트에 여러 검색창을 넣을 수 있습니다. 기존 DataviewJS 스크립트는 별도 진입점으로, 이 플러그인의 업데이트 대상이 아닙니다.

## 필터와 프리셋

결과 항목의 제외 아이콘으로 해당 노트나 상위 폴더를 제외하세요. 메뉴 상단에서 **临时过滤**(임시 필터) 또는 **写入预设**(프리셋에 저장)를 선택합니다. 임시 필터는 현재 검색에만 적용됩니다. 결과 도구 모음의 필터에서는 규칙을 편집하고, **保存为预设**를 눌러 이름 입력 화면으로 이동한 뒤 저장합니다.

| 예제 | 일치 대상 |
| --- | --- |
| `Projects/Archive` | 해당 폴더와 하위 경로 |
| `path:Projects/[notes]` | 대괄호를 포함한 경로 그대로 |
| `glob:**/assets/**` | 루트를 포함한 모든 깊이의 assets 폴더 |
| `glob:**/{assets,attachments,附件}/**` | 여러 첨부 폴더 이름 |
| `regex:/\.(png|jpe?g|gif|webp|svg|pdf)$/i` | 대소문자 구분 없이 이미지와 PDF |
| `exclude:path:Work/assets` | 허용 목록과 함께 사용할 수 있는 강제 제외 |

한 줄에 규칙 하나를 입력합니다. `**/assets/**`는 정규식이 아닌 **glob**입니다. `*`는 경로 한 구간 안에서, `**`는 여러 폴더에 걸쳐 일치합니다. 차단 목록은 일치 항목을 제외하고, 허용 목록은 일치 항목만 남깁니다. 여러 규칙 중 하나에라도 일치하면 적용됩니다. 정규식은 `regex:`로 시작해야 합니다. Obsidian 기본 검색 문법 전체를 지원하지는 않습니다. 잘못된 규칙은 저장 전에 알려 줍니다.

설정은 JSON 대신 표와 하위 페이지로 편집합니다. 항목 편집 후 **应用**(적용)을 누른 다음, 상위 표에서 **保存修改**(변경 저장)를 누르세요. 적용 없이 돌아가면 해당 항목의 변경은 반영되지 않습니다.

## 데이터와 개인정보

설정은 `data.json`, 검색 기록은 `history/`에 저장되고 본문 색인은 메모리에만 유지됩니다. 큰 보관함은 첫 검색에 시간이 걸릴 수 있습니다. 색인 재구축 명령어도 제공됩니다. 기록 일수 설정은 표시 범위만 바꾸며 기록 파일을 자동 삭제하지 않습니다.

텔레메트리가 없으며 보관함 밖 파일을 읽지 않습니다. **전체 및 인터넷 모드에서는 입력 내용이 활성화된 검색 엔진의 자동 완성 API로 전송될 수 있습니다.** 원하지 않으면 해당 엔진을 끄거나 자동 완성 URL을 비우세요. 웹 검색을 실행하면 검색 URL이 열립니다. 내부 웹 표시는 Obsidian Web viewer가 필요하며, 사용할 수 없으면 외부 브라우저를 엽니다.

## 문제 해결

결과가 없으면 검색 대상, 선택 범주, 프리셋 및 임시 필터를 확인하세요. 표시 문제가 있으면 기본 테마와 비교하고 [Issues](https://github.com/lmce72/obsidian-radar-search/issues)에 플러그인/Obsidian 버전, 기기, 테마, 재현 절차를 남겨 주세요. 스크린샷과 로그에서 개인정보를 지워 주세요.

## 개발 및 기여

TypeScript 및 Bun 1.3+를 사용합니다. 런타임 API는 Obsidian이 제공합니다.

```sh
bun install --frozen-lockfile
bun run check
bun test --timeout 5000
bun run build
```

빌드 결과는 `dist/`에 생성됩니다. UI, 검색/색인, 설정, 기록은 각각 `src/ui/`, `src/search/`, `src/settings/`, `src/history/`에 있습니다. 별도 테스트 보관함에서 검색창/페이지 및 실제 읽기 보기/실시간 미리보기 임베드를 확인하세요. 레이아웃 검증은 실제 기기의 터치 테스트를 대체하지 못합니다.

배포 규칙은 [AGENT.MD](../AGENT.MD)를 참조하세요. 태그와 Release 제목은 manifest 버전과 정확히 같은 숫자(예: `1.3.5`)여야 하며 `v`를 붙이지 않습니다. `bun run release:check <version>`을 실행하고 플러그인 세 파일만 게시하세요.
